# GeoJSON 科技地图工作台

一个在浏览器中把 GeoJSON 区域边界和可选业务数据转换为科技感三维数据地图的轻量工具。

## 产品线边界

本仓库现有两条有意分开的产品线：

- `main`：保留原来的重庆创业扶持数据大屏，作为数据大屏样例和个人作品。
- `codex/geojson-map-studio`：当前工具产品线，面向可复用的 GeoJSON 地图创作流程。

本地标签 `data-bigscreen-sample-v1` 固定指向分叉时的 `main` 样例快照。当前工作线不再以某个地区、行业或单次大屏交付为产品中心。

## 当前能力

- 上传 GeoJSON 后直接识别并加载 Polygon、MultiPolygon 及洞结构。
- 为每个区域设置展示名称、启用状态、主数值与次数值。
- 通过“更新此分块”“更新指标”或“全部更新”原子更新地图柱体、徽标与悬浮窗。
- 保留科技蓝材质、三维挤出、HUD、光效、粒子与地图 Hover 反馈。
- 自定义几何保存在浏览器中；业务数据仅在当前页面会话中存在，刷新即清除。
- 无效文件或不完整数值不会覆盖上一版有效地图。

## 当前非目标

- 账号、云端项目和跨设备同步。
- 收费版业务数据持久化。
- 图片、视频或可嵌入组件导出。
- SVG、Shapefile、KML、CSV 或 Excel 导入。
- 面向特定地区或行业继续扩展固定数据大屏板块。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

质量检查：

```bash
npm test -- --dir src
npm run typecheck
npm run build
```

## 方向说明

当前阶段优先完善“导入边界 → 配置区域数据 → 即时查看科技感地图”的最短创作链路。未来的项目保存、导出与商业化能力应建立在这条通用链路之上，而不是重新耦合到旧数据大屏样例。
