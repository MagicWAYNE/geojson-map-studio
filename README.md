# GeoJSON 科技地图工作台

一个基于 Three.js 的数据地图项目。选择内置区域或导入 GeoJSON 后，即可在浏览器中获得视觉完成度较高的三维数据地图模型。

地图可用于数据大屏、指挥舱页面、PPT、公众号、小红书，以及其他需要地图可视化素材的场景。

![GeoJSON Map Studio 功能预览](./preview.gif)

## 产品线边界

这个独立仓库由原数据大屏项目分叉而来，两条产品线按以下方式保留：

- 当前仓库的 `main`：GeoJSON 地图工具产品线，面向可复用的地图创作流程。
- `data-bigscreen-sample-v1` 标签：分叉时的重庆创业扶持数据大屏，作为样例与个人作品快照。

原项目的 `main` 仍保留旧数据大屏，不因这个新仓库的创建而改变。当前仓库不再以某个地区、行业或单次大屏交付为产品中心。

## 当前能力

- 从内置区域库选择地图，或上传 GeoJSON 并识别 Polygon、MultiPolygon 及洞结构。
- 为每个区域设置展示名称、启用状态、主数值与副数值。
- 通过“更新此分块”“更新指标”或“全部更新”原子更新地图柱体、徽标与悬浮窗。
- 提供科技蓝材质、三维挤出、HUD、光效、粒子、自动 Hover 轮播与地图交互反馈。
- 提供构图、相机、柱状图、悬浮窗和地图效果等视觉样式参数。
- 支持为已准备的内置区域加载项目本地 Sentinel-2 影像，不依赖运行时第三方影像 API。
- 自定义几何保存在浏览器中；业务数据仅在当前页面会话中存在，刷新即清除。
- 无效文件或不完整数值不会覆盖上一版有效地图。

## 使用指引

1. 选择内置区域，或上传 GeoJSON 文件来获得自己想要的区域。需要准备其他区域数据时，推荐使用[阿里云 DataV 数据可视化平台的 GeoJSON 工具](https://datav.aliyun.com/portal/school/atlas/area_selector)。
2. 在“分块数据配置”中添加数据，即可实现柱状图和选中后展示数据的效果。
3. 使用鼠标调整模型：左键拖动旋转模型角度，中键拖动调整缩放，右键拖动调整位置。
4. 在“视觉样式”中继续调整已开放的构图、视角和地图效果参数，形成自己的视觉方案。

## 当前非目标

- 账号、云端项目和跨设备同步。
- 收费版业务数据持久化。
- 图片、视频或可嵌入组件导出。
- SVG、Shapefile、KML、CSV 或 Excel 导入。
- 面向特定地区或行业继续扩展固定数据大屏板块。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

质量检查：

```bash
npm test -- --dir src
npm run typecheck
npm run build
```
