# Sentinel-2 local imagery data notice

Contains modified Copernicus Sentinel data 2025.

Source: Copernicus Data Space Ecosystem, Sentinel-2 Level-3 Quarterly Mosaics (2025).

Legal notice: https://sentinels.copernicus.eu/documents/247904/690755/Sentinel_Data_Legal_Notice

The JPEG textures in this directory are modified, projected, resampled and color-transformed derivatives generated for local map visualization.
