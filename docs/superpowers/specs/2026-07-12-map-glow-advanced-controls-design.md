# 地图常态柔光与高级调试参数设计

日期：2026-07-12

状态：已确认，待实施计划

## 背景

当前真实外扩柔光管线已经支持常态与 hover 两个独立通道，但已批准的 v1 默认配置把四个辉光半径/透明度值设为 0。零值短路使页面恢复默认值后常态没有外扩柔光；用户只能在保存过非零 hover 参数时看到 hover 柔光。

本设计把已在真实页面验收的常态 B3 参考值 `54 px / 0.23` 固化为新默认，并把当前写死在 profile、Shader 和管线中的安全视觉参数开放到“地图调试”抽屉。

## 目标

1. 页面首次加载和恢复默认值后，地图常态外圈立即显示真实外扩柔光。
2. 常态与 hover 的高级视觉参数相互独立。
3. 抽屉尽可能完整地开放肉眼可感知且能安全校验的柔光参数。
4. 保持现有遮罩、多级模糊、外侧裁切、运行期降级和资源生命周期架构。
5. 支持实时预览与草稿应用两种调试方式，并复制完整可复现配置。
6. 迁移 v1 缓存时保留用户自定义值，且让未自定义的旧默认缓存获得新的常态柔光。

## 非目标

- 不开放 Gaussian 原始采样权重、采样表达式或会破坏纹理反馈安全的底层对象。
- 不改变地图数据、柱状图、标记、tooltip、点击下钻或详情页。
- 不修复已知的“两江新区”详情数据缺失。
- 不改变外扩柔光的屏幕 CSS px 语义。
- 不把 100% 离屏精度或高模糊次数设为默认值。

## 配置版本与存储

配置升级为 `MapEffectConfig` version 2，存储键升级为：

```text
cq-map-effect-config-v2
```

v1 键保留为只读迁移来源，不再写入。

### 迁移规则

1. 优先读取合法 v2 配置。
2. 没有 v2 配置时读取 v1。
3. v1 原始对象完全等于当前已批准 v1 默认值时，迁移为完整 v2 新默认值。
4. v1 为自定义配置时，保留所有已有字段值，并用 v2 默认值补齐新增字段。
5. 损坏、不支持或非对象缓存回退为完整 v2 默认值。
6. 首次成功保存后只写 v2 键。

这意味着旧默认缓存中的常态 `0 / 0` 会迁移为 `54 / 0.23`；用户明确调过的 v1 参数继续保留，包括自定义的 0 值。

## v2 配置结构

### 常态边界与柔光

`base` 保留现有内部线和外圈亮芯字段，并增加独立柔光颜色与高级参数：

```json
{
  "innerColor": "#ffffff",
  "innerWidth": 1.5,
  "innerOpacity": 0.55,
  "outerColor": "#ffffff",
  "outerCoreWidth": 2,
  "outerGlowEnabled": true,
  "outerGlowColor": "#ffffff",
  "outerGlowWidth": 54,
  "outerGlowStrength": 0.23,
  "outerGlowNearRadiusRatio": 0.35,
  "outerGlowNearOpacityRatio": 0.83,
  "outerGlowFarRadiusRatio": 1,
  "outerGlowFarOpacityRatio": 1,
  "outerGlowFalloff": 1,
  "outerGlowEdgeSoftness": 0.96,
  "outerGlowNearPasses": 2,
  "outerGlowFarPasses": 4
}
```

常态柔光颜色从 `outerColor` 分离。默认仍为白色，保证外观与已验收的 `54 / 0.23` 基准一致。

### Hover 表面、轮廓与柔光

`hover` 保留现有表面、自发光、亮芯、抬升和时长字段，并增加：

```json
{
  "glowEnabled": true,
  "glowColor": "#27a7ff",
  "glowWidth": 0,
  "glowStrength": 0,
  "glowNearRadiusRatio": 0.35,
  "glowNearOpacityRatio": 0.83,
  "glowFarRadiusRatio": 1,
  "glowFarOpacityRatio": 1,
  "glowFalloff": 1,
  "glowEdgeSoftness": 0.96,
  "glowNearPasses": 2,
  "glowFarPasses": 4
}
```

本轮不把 hover 半径/透明度改为非零默认；用户可在抽屉中独立调试后再决定是否固化。

### 全局渲染质量

顶层增加：

```json
{
  "quality": {
    "renderScale": 0.5,
    "maxAlpha": 1
  }
}
```

实时预览属于抽屉会话状态，不进入复制 JSON。

## 参数范围与语义

常态和 hover 使用相同范围、不同字段：

| 参数 | 范围 | 步长 | 语义 |
| --- | ---: | ---: | --- |
| 启用柔光 | true/false | - | 保留配置但跳过/恢复通道 |
| 柔光颜色 | `#rrggbb` | - | 模糊合成颜色 |
| 总扩散半径 | 0–200 px | 1 | 屏幕 CSS px 基准 |
| 总体透明度 | 0–1 | 0.01 | 通道整体强度 |
| 近端扩散倍率 | 0–1.5 | 0.01 | 近端半径相对总半径 |
| 近端透明度倍率 | 0–2 | 0.01 | 近端强度相对总体透明度 |
| 远端扩散倍率 | 0.25–2 | 0.01 | 远端半径相对总半径 |
| 远端透明度倍率 | 0–2 | 0.01 | 远端强度相对总体透明度 |
| 衰减曲线 | 0.25–4 | 0.05 | `pow` 指数；小于 1 提亮尾部，大于 1 收紧尾部 |
| 外侧裁切柔度 | 0–1 | 0.01 | 轮廓内侧遮罩过渡宽度 |
| 近端模糊次数 | 1–8 | 1 | 近端可分离模糊迭代数 |
| 远端模糊次数 | 1–8 | 1 | 远端可分离模糊迭代数 |

全局质量参数：

| 参数 | 允许值 | 默认 |
| --- | --- | --- |
| 离屏渲染精度 | 0.25 / 0.5 / 0.75 / 1 | 0.5 |
| 合成透明度上限 | 0.1–1，步长 0.05 | 1 |

所有数字必须有限并被裁剪到范围；模糊次数必须规范化为整数。非法颜色逐字段回退。

## 抽屉信息架构

“地图调试 → 效果”依次展示：

1. 常态边界
2. 常态外扩柔光
3. Hover 表面
4. Hover 外扩柔光
5. 渲染质量与性能
6. 可复制参数

每个柔光组提供启用、颜色、半径、透明度、四个近远端倍率、衰减、裁切柔度、近远端模糊次数。

### 组级操作

- `应用 B3 参考预设`：只恢复倍率、衰减、裁切柔度与模糊次数；不覆盖颜色、半径和总体透明度。
- `重置本组`：恢复该组完整 v2 默认值。
- `恢复全部默认值`：恢复完整 `MAP_EFFECT_DEFAULTS` v2。

### 实时预览与草稿

- 实时预览默认开启，控件逐项写入响应式配置、渲染管线和 v2 localStorage。
- 关闭实时预览后，所有控件编辑本地深拷贝草稿。
- `应用参数` 把草稿整体规范化后写入响应式配置。
- `放弃草稿` 用当前已生效配置覆盖草稿。
- 外部重置或缓存重新加载时，草稿同步到新的已生效配置。
- 实时预览状态不写入 JSON，也不跨页面持久化。

## 运行状态显示

“渲染质量与性能”展示：

- 当前 RenderTarget 宽 × 高；
- 当前离屏精度；
- 常态通道：启用 / 参数为零跳过 / 手动关闭；
- hover 通道：启用待触发 / 活跃 / 参数为零跳过 / 手动关闭；
- 运行状态：正常 / 外扩柔光已降级关闭。

管线或组件只在状态值变化时更新调试模块，不能每帧触发 Vue 响应式写入。

## 渲染参数数据流

当前写死的 B3 profile 改为从常态或 hover 配置派生：

```text
nearRadius = totalRadius × nearRadiusRatio
farRadius  = totalRadius × farRadiusRatio
nearAlpha  = totalOpacity × nearOpacityRatio
farAlpha   = totalOpacity × farOpacityRatio
```

派生结果继续乘 `pixelsPerCssPx`，保持屏幕像素稳定。

### Dirty 规则

需要重新生成对应通道模糊：

- 总半径；
- 近/远端半径倍率；
- 近/远端模糊次数；
- 全局 renderScale；
- 相机、容器、DPR 或 `ScaleScreen`。

只需重新合成：

- 柔光颜色；
- 总体透明度；
- 近/远端透明度倍率；
- 衰减曲线；
- 裁切柔度；
- maxAlpha。

启用开关关闭时跳过对应通道；重新启用时，只要影响模糊的参数和视图没有变化，就复用已有缓存。

## Shader 变化

Gaussian 采样表达式和权重保持固定。

合成 Shader 新增每个通道的：

- `uFalloff`；
- `uEdgeSoftness`；
- 全局 `uMaxAlpha`。

合成顺序为：读取 mask/near/far → 应用近远端透明度 → 合并 → 应用稳定范围内的 `pow` 衰减 → 外侧裁切 → `maxAlpha` 限制 → 加法合成。

Shader 参数在 CPU 端完成有限值和范围规范化；Shader 内仍使用 clamp 防御。

## 性能与安全

- 默认 renderScale 保持 0.5，近端 2 次、远端 4 次。
- 100% 精度或较高模糊次数允许用于调试，但抽屉显示性能提示。
- 参数为零、通道关闭或 hover 不活跃时继续短路。
- RenderTarget resize 复用现有对象，不因滑块变化重复分配对象。
- 运行期异常继续一次性关闭外扩柔光、释放管线并直接渲染主场景。
- 原始 Shader 权重和纹理对象不进入配置，防止非法反馈或无法迁移的参数。

## 测试策略

### 配置与迁移

- 精确 v2 默认对象，包括常态 `54 / 0.23`。
- v1 当前默认缓存迁移到完整 v2 默认。
- v1 自定义缓存保留已有值并补齐高级字段。
- v2 损坏、缺字段、越界、非有限值、非法颜色和非整数 passes。
- v2 保存键、复制 JSON、恢复默认值。

### 抽屉

- 所有字段稳定 label/id、范围和步长。
- 常态/hover 独立编辑。
- 启用开关保留数值。
- 实时预览开启立即写入。
- 实时预览关闭只更新草稿；应用与放弃行为正确。
- B3 预设不覆盖颜色、半径、总体透明度。
- 分组重置与全部重置隔离正确。
- 运行状态与性能提示可访问。

### Profile、Shader 与管线

- 自定义近/远端半径和透明度倍率派生。
- 自定义 passes 被传入正确 blur 调用。
- falloff、softness、maxAlpha uniforms 正确绑定并保持有限。
- dirty 分类验证“重模糊、仅合成、跳过、缓存复用”。
- renderScale 改变所有 RenderTarget 尺寸，CSS px 视觉半径不变。
- 运行状态仅在变化时发布。
- 运行期失败降级保持现有一次 warning、一次 dispose 和后续直接渲染。

### 浏览器验收

- 恢复默认值后无需 hover 即可看到 `54 / 0.23` 常态柔光。
- 所有高级参数在真实页面热更新，并能复制、刷新后复现。
- 实时预览关闭时页面不随草稿变化，应用后一次性更新。
- 常态和 hover 可分别关闭、重置和应用 B3 预设。
- 25%–100% 精度、1–8 次模糊不产生黑屏或持续控制台错误。
- 默认参数维持常态 ≥55 FPS、连续 hover ≥50 FPS。

## 验收标准

1. 新用户、旧 v1 默认缓存用户和点击“恢复全部默认值”的用户都能看到常态柔光。
2. 用户能在抽屉中独立调节常态与 hover 的所有已定义高级参数。
3. 复制的 v2 JSON 能在刷新后复现同样效果和质量设置。
4. 参数变化只触发设计规定的最低成本更新路径。
5. 非法和高负载参数保持受控；运行异常不影响地图主体和交互。
6. 自动测试、类型检查、生产构建、整分支 diff 和真实浏览器验收通过。
