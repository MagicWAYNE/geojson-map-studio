# 地图区级案件量发光柱状图设计

日期：2026-07-13

状态：交互设计已确认，待详细实施计划

## 目标

在现有重庆 3D 地图的 8 个区块上，为每个区展示一根代表案件量的 3D 发光柱体。柱体属于地图同一 Three.js 场景，随地图视角自然透视和旋转；现有地图边界、外扩/内扩柔光、hover、tooltip 与点击下钻必须保持可用。

本期范围只显示一个指标：`DistrictMapItem.aj`（案件量）。`ztje`（在调金额）和 `zzs`（调解组织数）继续留在现有 hover tooltip，不绘制多系列柱状图。

## 已确认的视觉与交互规则

- 柱体采用 B「发光数据塔」风格：中等宽度半透明青蓝光柱，底部弱光环，常态没有区名或数值标签。
- 柱高按案件量的开方归一化映射，保留大小排序，同时避免高值区压扁其余区的可见差异。
- 柱体锚定在对应区块的内部安全点，而不是简单几何中心；锚点不得落到区外、边界或孔洞内。
- 两江新区继续使用既有逻辑：江北区和渝北区案件量之和。
- 地图完成初始加载后，柱体仅执行一次稳定顺序的错峰升起动画；之后不循环跳动。
- hover 某区时，仅该区的柱体提亮并轻微上浮，离开后平滑恢复；其他柱体保持原样。
- 柱体不参与点击射线检测，现有区块继续独占 hover、tooltip 和点击下钻。

## 技术方案

采用独立网格层，而非 instancing、HTML 覆盖层或全屏后处理。

### 架构

在 `ChongqingMap3D.vue` 中增加 `DistrictBarLayer`。它与区块网格、边界线、静态/hover 宽线和现有屏幕空间柔光并列加入同一个地图 group，因此柱体共享地图局部坐标、相机和资源生命周期。

建议将以下纯逻辑从 Vue 组件中拆出为可测试模块：

- 从 projected region 几何中计算稳定的区内安全锚点；
- 将案件量映射为柱高的开方归一化函数；
- 归一化、迁移、复制和格式化柱状图配置；
- 创建、更新、动画和释放柱体层的 Three.js 资源。

当前 SVG 恰有 8 个区块，使用每区独立网格更易于实现单区 hover、可调材质和安全资源回收。无需为当前规模引入 `InstancedMesh`。柱体不会接入已有外扩/内扩柔光渲染管线；其本体材质和底部光环负责视觉发光，避免增加屏幕空间管线的性能与耦合风险。

### 数据流

1. `getDistrictMapData()` 提供区名、案件量、在调金额和组织数。
2. 地图初始化时补齐两江新区数据，与现有区块数据保持同名键映射。
3. 解析 SVG 并投影区块几何后，为每个渲染区找安全锚点。
4. `DistrictBarLayer` 仅为具有有限、非负案件量的数据项创建柱体；缺失或非法数据不阻断地图加载。
5. 启动一次错峰入场动画；每帧将当前 bar 配置和对应区块的 hover progress 应用于该柱体。
6. 组件卸载或重新初始化时，统一释放柱体几何与材质。

### 安全锚点

安全锚点按以下优先顺序计算：区块面积加权中心、形状包围盒中心、确定性的内部采样点。每一步都用区块外环和孔洞做点内测试；一旦通过即使用。所有候选失败时跳过该区的柱体并记录一次诊断，不影响区块主体、边界、tooltip 或下钻。

## 配置与调试

地图效果配置升级到包含 `bars` 段的新版本。`bars` 至少包含：

```ts
interface MapDistrictBarConfig {
  enabled: boolean
  color: string
  opacity: number
  width: number
  minHeight: number
  maxHeight: number
  sqrtExponent: number
  glowStrength: number
  baseRingRadius: number
  baseRingOpacity: number
  enterMs: number
  staggerMs: number
  hoverEmissiveIntensity: number
  hoverLift: number
}
```

字段会在加载、存储、复制和重置前归一化：颜色必须有效；非有限值回退默认值；尺寸、透明度、动画时间和强度裁切到明确范围。已有 v3 地图柔光配置在迁移时保留其现有值，只为 `bars` 注入默认配置。

“地图调试”抽屉新增“柱状图”分组，提供总开关、颜色、透明度、柱宽、最小/最大高度、开方映射强弱、底部光环尺寸/透明度、入场时长、错峰间隔、hover 提亮强度和上浮距离；显示当前有效柱数及案件量映射范围。可复制 JSON、重置效果、localStorage 持久化与现有地图效果保持一致。

默认调色与地图现有白边、青蓝柔光协调：冷青蓝柱体、白青色边缘高光、克制的底部光环，不添加常态文本标签。

## 异常处理与性能

- 任一区块的缺失数据、无效锚点或资源创建失败，仅跳过该区柱体并记录一次可诊断警告。
- 柱体层失败不得影响地图区块、hover、tooltip、点击下钻或既有柔光；地图主体继续渲染。
- 仅维护 8 套柱体和光环资源，不增加全屏后处理，也不使柱体成为 raycast 目标。
- 入场与 hover 仅更新已有对象的缩放、位置和材质 uniform/属性，不在动画帧重建几何或材质。

## 验证范围

- 数据：两江新区合并案件量、开方映射单调性、最小/最大高度、异常值回退。
- 几何：安全锚点在对应区块内且不在孔洞内；缺失锚点时能局部降级。
- 运行时：一次性错峰入场，hover 只影响目标柱体，点击仍由区块触发下钻。
- 配置：默认值、旧配置迁移、归一化、复制、抽屉重置与 localStorage 持久化。
- 回归：现有地图柔光与调试测试、`npm run typecheck`、`npm test`、`npm run build`。

## 不在本期范围

- 多指标、堆叠柱、分组柱或常态柱顶标签；
- 全市 38 区县地图扩展和面向大量实例的 InstancedMesh 优化；
- 将柱体光效接入现有外扩/内扩屏幕空间柔光管线；
- 修改区块点击路径、tooltip 数据字段或下钻页内容。
